## 2. Бюджет

На контроль нужно примерно $0,25, запас есть. Главный риск: потратить остаток до 11:00.

| Действие | Цена |
|---|---|
| `make prod`, 10 контрольных чатов | $0,25, в худшем случае около $0,50 |
| Замена критерия на 10 диалогах, галочка «только изменённые» включена | Несколько центов |
| Смена веса критерия | $0 |
| «Переоценить» на той же версии чек-листа | $0 |
| Whisper | $0, работает локально |
| **Не запускать:** `make evaluate-all` на новой версии | Около $1,6 |
| **Не запускать:** `bench --repeat 2` | Около $0,55 |
| **Не запускать без нужды:** `make bench` | Около $0,25 на новой версии |
| **Не запускать без нужды:** `npm run e2e` | Несколько центов за прогон |
| **Не нажимать без нужды:** «Пересчитать заново» | Около $0,02 до $0,05 за диалог |

Правка файла чек-листа создаёт новую версию. После этого экспорт DEV откажет, пока все 65 диалогов не будут оценены заново, а на это денег не хватит с запасом. Файл `checklists/freedom_default.json` до сдачи не менять. Критерии на демо меняются через редактор.

Новая версия с теми же весами и шкалами, созданная в редакторе, тоже считается подходящей для сдачи. Если сохранить такую версию до `make prod`, контрольные чаты будут оценены ею. Поэтому до контроля в редакторе ничего не сохранять, либо передать нужную версию явно: `--version 5`.

## 3. План на утро

1. **Около 10:30.** Открыть репозиторий и проверить ссылку в режиме инкогнито:

   ```powershell
   gh repo edit GeorgeTolen/real-couple --visibility public --accept-visibility-change-consequences
   ```

2. **Отправить ссылку организаторам,** когда придёт форма.
3. **Около 11:00.** Запустить контрольный прогон в новом терминале. Команда сама импортирует чаты, оценит их, проверит файл, закоммитит и запушит:

   ```powershell
   make prod GROUP=<id контрольного набора>
   ```

4. **До 12:00.** Убедиться, что `results/prod/results.json` открывается по ссылке без входа в аккаунт.

## 5. Что учесть на защите

- **Запуск.** Приложение работает на ноутбуке: `make run`, адрес `http://localhost:8000`. База не входит в репозиторий, поэтому на чужой чистой установке список будет пуст, пока не выполнить импорт и оценку. Показывать лучше со своего ноутбука.
- **Пробная апелляция.** В базе осталось ваше решение по `p1-en-014`, которое сняло грубую ошибку. Поэтому в интерфейсе грубых нарушений 7, а в файле сдачи 8. На сдачу это не влияет.
- **Whisper.** Текст скрыт по умолчанию, маски стоят на местах скрытых данных. Это эвристика, поэтому перед показом просмотрите текст.
- **Флаг «На проверку».** Стоит у 1 диалога из 65, потому что арбитр почти всегда принимает сторону одного из судей. Если спросят, это сознательное правило.
- **Смена чек-листа на демо.** Аналитика по умолчанию показывает самую полную версию. Новая версия выбирается в фильтре.
