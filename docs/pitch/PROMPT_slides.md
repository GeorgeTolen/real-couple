# Промпт 2. Презентация для защиты CQA (Claude Code, Opus 5.5)

Отдай агенту целиком. Работать в новой папке `pitch/slides/` в корне репозитория, приложение не трогать.

## 0. Задача и скиллы
- Защита 5 минут. Freedom просил прежде всего **живое демо**. Слайды нужны до демо (зачем и как построено, 1,5 минуты) и после (цифры и что дальше, 1 минута). Демо идёт из приложения, в презентации только слайд-подсказка с порядком демо.
- Скиллы: загрузи **frontend-design** до первой строки кода. Для проверки и экспорта PDF используй **webapp-testing** (Playwright), если есть; иначе Playwright напрямую.
- Формат: одна самодостаточная HTML-презентация `pitch/slides/dist/index.html` (Vite + TypeScript, без фреймворков слайдов или с минимальным своим движком, сборка в один файл через `vite-plugin-singlefile`). Плюс резерв `pitch/slides/dist/cqa-pitch.pdf` и PNG каждого слайда в `pitch/slides/dist/png/`.
- Холст 1920×1080, масштабирование под экран с сохранением пропорций, работает офлайн.

## 1. Материалы (уже в репозитории)
- `docs/pitch/data/model_benchmark.json`, `research.json`, `journey.json`, `facts.json`: все цифры, цитаты, хронология, архитектура.
- `docs/screens/2x/*.png`: снимки интерфейса без рамок, вырезки октагона и паспорта критерия.
- `frontend/src/app.css`: токены цвета и шрифтов. `docs/design/rule_nested_radius.png`: правило радиусов.

Все цифры только из этих файлов. Ничего не придумывать.

## 2. Управление
- Стрелки и пробел: следующий шаг или слайд. Каждый слайд собирается по шагам (2 до 4 шага), график анимируется при входе.
- `N`: окно заметок докладчика (текст, таймер, следующий слайд) в отдельном окне через `window.open` и `BroadcastChannel`.
- `G`: сетка всех слайдов. `F`: полноэкранный режим. `P`: режим печати без анимаций для PDF.
- Тонкая полоса прогресса снизу, номер слайда моноширинным шрифтом.
- `prefers-reduced-motion`: все шаги сразу, без анимации.

## 3. Визуальный язык
- Как в продукте «Журнал контроля»: фон `#f6f5f1`, карточки белые, линии `#e3e1da`, текст `#1c1f1d`, акцент `#138a4e`, тёмно-зелёный `#0e3b27` для титула, разделителя демо и финала. Статусы: да `#1f7a4d`, нет `#b4232c`, на проверку `#a35f00`, N/A `#6b6f76`.
- Segoe UI Variable для текста, Cascadia Mono или JetBrains Mono для чисел.
- На слайде одна мысль: заголовок до 7 слов, остальное графики, схемы, снимки, цитаты. Никаких списков длиннее 3 пунктов.
- Графики рисовать SVG вручную (без тяжёлых библиотек), подписи значений прямо на графике, одна ось Y, одна легенда.
- Радиусы: внешний = внутренний + отступ. Сетка 8 px.
- Без длинных тире в тексте слайдов.

## 5. Заметки докладчика
Для каждого слайда 2 до 3 предложения разговорным языком, в сумме на слайды 1 до 7 не больше 90 секунд чтения, на 9 до 11 не больше 60 секунд. Заметки на русском.

## 6. Проверка
1. `npm run build` без ошибок, один HTML, работает из файла без сервера и без сети.
2. Playwright: PNG каждого слайда в финальном состоянии и PDF 16:9 из режима печати.
3. `pitch/slides/numbers-check.md`: каждое число → файл и поле.
4. Цитаты дословно совпадают с `quote`, не длиннее 15 слов, с источником на слайде.
5. Тайминг: прогон заметок вслух укладывается в 2,5 минуты без демо.
6. `pitch/slides/README.md`: как открыть, клавиши, как пересобрать PDF.
