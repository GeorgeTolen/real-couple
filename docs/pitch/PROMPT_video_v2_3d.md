# PROMPT: видео v2, 30 секунд, 3D, под сценарий выступления

Ты Claude Code (Opus 5.5) в репозитории `real-couple`. Переделай ролик в `pitch/video/` под новый сценарий. Старая раскадровка из `docs/pitch/PROMPT_video_30s.md` отменяется, кроме технических требований: Remotion, 1920×1080, 30 fps, **900 кадров**, H.264 до 25 МБ, постер, `numbers-check.md`, `voiceover.txt`, README. Сцену «2 до 3% вручную» убрать совсем. Экраны продукта в ролик не берём, кроме двух скриншотов диалогов из сцены 6.

Скиллы: `remotion` (если есть), `vizavi-motion`, `frontend-design`. 3D через `@remotion/three` и `three`. Готовая геометрия монет: `pitch/slides/src/coins.ts` и `frontend/src/components/TengeCoins.tsx`, переиспользуй её, не рисуй монеты заново.

Факты только из `docs/pitch/PITCH_analysis.md`, `docs/pitch/data/*.json`, `bench/results_ensemble.json`, `bench/holdout/holdout_report.json`. Без длинных тире. Ролик идёт перед выступлением, поэтому он показывает ту же историю, что слайды `PROMPT_slides_v4_script.md`, только быстрее и объёмнее.

## Визуальный язык

- Два мира. **Тёмный** (`#0e3b27`, глубже к краям `#082518`) для 3D-сцен: титул, перекосы, конвейер, финал. **Светлый** (`#f6f5f1`) для данных: графики, скриншоты. Переход между мирами через шторку тёмно-зелёного цвета за 8 кадров, не кроссфейд.
- Шрифты как в деке: Unbounded для заголовков и больших чисел (вес анимируется 250 → 700 за 20 кадров), Onest для подписей, JetBrains Mono для чисел в данных, `tabular-nums`.
- 3D-материалы матовые: зелёный `#138a4e` с лёгким металлом (metalness 0.6, roughness 0.35), тёмно-зелёный, белый матовый. Один мягкий ключевой свет сверху-слева, один контровой, environment без видимых бликов-«шаров». Никакого неона, bloom и стеклянных плашек. Тени мягкие, контакт с полом виден.
- Камера движется медленно и всегда по одной оси за сцену: наезд, проезд или орбита до 12°. Spring без отскока. Кадр не вращаем.
- На кадре не больше 5 крупных слов. Числа считаются одометром (разряды прокручиваются колонками), как в деке.
- Все 2D-элементы соблюдают правило радиусов: внешний = внутренний + отступ.

## Текст для голоса (`voiceover.txt`, около 27 секунд)

1. LLM-судья предвзят: порядок, длина, нестабильность. Потолок людей каппа ноль восемь.
2. Наша цель: стабильно и честно. Восемь критериев, снижение только с номером реплики.
3. Поймали разброс восемьдесят пять и восемьдесят с половиной. Добавили слой согласованности: девяносто пять из девяноста шести.
4. Локально восемьдесят четыре процента. В облаке три модели, два цента за диалог.
5. Факты считает код, судят две модели разных вендоров, спорное решает арбитр.
6. Тридцать восемь против ста за один и тот же вопрос, разница в словах. Каппа ноль девяносто шесть.

## Проверка

1. Ровно 900 кадров, MP4 до 25 МБ, постер кадр 885.
2. `pitch/video/out/numbers-check.md`: каждое число → файл и поле.
3. В ролике нет «3%», «сотни прогонов», «два арбитра».
4. 3D-сцены рендерятся детерминированно (без `Math.random` вне seed), повторный рендер даёт тот же кадр.
5. Просмотр на 0,5x: каждая надпись держится не меньше 1,5 с, скриншоты читаются.
6. Рендер на CPU укладывается в 10 минут. Если `@remotion/three` не поднимается, 3D-сцены заменить на предрендеренные PNG-секвенции из three.js (скрипт в `pitch/video/scripts/`), ролик всё равно собирается.
7. Коммит `pitch: video v2, 3d scenes under the speaking script`.
