# Промпт 1. Видео 90 секунд для защиты CQA (Claude Code, Opus 5.5)

Отдай агенту целиком. Работать в новой папке `pitch/video/` в корне репозитория, приложение не трогать.

## 0. Задача и скиллы
- Мы команда хакатона Freedom Broker. Продукт: система контроля качества чатов и звонков поддержки (код в этом репозитории).
- Нужен ролик на 90 секунд, который открывает защиту. После него идёт живое демо, поэтому ролик рассказывает «как и почему мы так построили», а не показывает все экраны.
- Скиллы: если есть скилл **remotion** (официальные Remotion best practices), загрузи его первым; затем **frontend-design**. Если скиллов нет, работай по документации Remotion.
- Инструмент: **Remotion** (React + TypeScript), 1920×1080, 30 fps, 2700 кадров. Итог: `pitch/video/out/cqa-90s.mp4` (H.264, до 60 МБ) и `pitch/video/out/poster.png`.

## 1. Материалы (уже в репозитории)
- `docs/pitch/data/model_benchmark.json`: 16 моделей, точность, по языкам, ошибка итога, цена и время за диалог, роли выбранных, сложность критериев.
- `docs/pitch/data/research.json`: источники, дословные короткие цитаты, вывод по-русски, что мы применили.
- `docs/pitch/data/journey.json`: хронология решений за сутки с цифрами.
- `docs/pitch/data/facts.json`: итоговые цифры, узлы и связи архитектуры, пример расчёта N/A, «что сделали сами».
- `docs/screens/2x/*.png`: снимки 2880×1800 без рамок; вырезки `c02-octagon-ru-009.png`, `c02-passport-identification.png`, `c03-octagon-ru-020.png`.
- Компонент монет: `frontend/src/components/TengeCoins.tsx` (three.js). Токены цвета и шрифтов: `frontend/src/app.css`.

Все цифры брать только из этих файлов. Ничего не придумывать и не округлять сильнее, чем в файлах.

## 2. Визуальный язык
- Палитра продукта: фон `#f6f5f1`, карточки белые, линии `#e3e1da`, текст `#1c1f1d`, акцент `#138a4e`, тёмно-зелёный `#0e3b27` для заставки и финала. Статусы: да `#1f7a4d`, нет `#b4232c`, на проверку `#a35f00`, N/A `#6b6f76`.
- Шрифты: Segoe UI Variable для текста, Cascadia Mono или JetBrains Mono для чисел, ID и номеров реплик.
- На кадре одна мысль: не больше 7 крупных слов и одна строка подписи. Рассказывают графики, схемы и движение.
- Цитата: карточка с тонкой рамкой, текст на языке оригинала, под ним источник мелким моноширинным и одна строка вывода по-русски.
- Движение: spring без отскока, появление 300 до 500 мс, смещение до 24 px, линии рисуются через stroke-dashoffset, числа считаются вверх, наезд камеры не больше 4% масштаба. Без вращений кадра, глитчей и неона. Радиусы: внешний = внутренний + отступ.
- Звука нет, ролик читается без голоса. Текст для чтения вживую положи в `pitch/video/out/voiceover.txt`.

## 4. Текст для голоса (`voiceover.txt`)
1. Вручную проверяют два, три процента диалогов. Мы оцениваем каждый, по каждому критерию, с номером реплики.
2. Мы не угадывали, а взяли выводы исследований про LLM-судей: сначала рассуждение, потом вердикт; второй судья другого вендора; отдельно точность и стабильность.
3. Модель выбрали турниром: шестнадцать моделей на нашем эталоне. Лучшая пара Gemini и GPT, арбитр только для спорного. Для ноутбука есть локальный режим.
4. Точность решают «Консультация» и «Завершение», туда мы вложили калибровку.
5. Пилот показал скачок оценки при повторе. Мы добавили кеш и правило: нет сбоя с номером реплики, нет снижения.
6. На десяти новых чатах, размеченных до прогона, девяносто семь и две десятых процента. Два цента за диалог.

## 5. Проверка
1. Рендер без ошибок, 2700 кадров, MP4 до 60 МБ, постер.
2. `pitch/video/out/numbers-check.md`: каждое число на экране → файл и поле, откуда оно.
3. Цитаты дословно совпадают с `quote`, не длиннее 15 слов, с источником.
4. Просмотр на 0,5x: текст успевает прочитаться, нигде нет больше 7 крупных слов.
5. `pitch/video/README.md`: как перерендерить.
