# Ролик v2: 3D, под сценарий выступления

Remotion, 1920×1080, 30 fps, H.264. Сюжет занимает 900 кадров по раскадровке, а в ключевых моментах стоят короткие стоп-кадры (`src/holds.json`), поэтому выходной ролик 1101 кадр, 36,7 с. Раскадровка в `docs/pitch/PROMPT_video_v2_3d.md`; ролик идёт перед выступлением и рассказывает ту же историю, что дека v4 (`docs/pitch/PROMPT_slides_v4_script.md`), только быстрее. Текст для чтения вживую в `out/voiceover.txt`, источники всех чисел в `out/numbers-check.md`.

## Перерендерить

```bash
cd pitch/video
npm install
npm run render   # out/cqa-30s.mp4
npm run poster   # out/poster.png, кадр сюжета 885 = выходной кадр 1086
npm run sound    # out/cqa-30s-sound.mp4: тот же ролик со звуком (нужны Python с numpy и scipy, ffmpeg)
npm run studio   # просмотр и правка в браузере
```

3D рендерится программным WebGL (`swangle`, включён в `remotion.config.ts`), видеокарта не нужна. Системный Chrome берётся, только если есть `/usr/bin/google-chrome`; на Windows и macOS Remotion скачает свой браузер при первом рендере. На 2 ядрах CPU полный рендер занимает около 6,5 минут.

Кадры в таблице это кадры сюжета. Паузы задаются в `src/holds.json` парами [кадр сюжета, длина]: `src/holds.ts` переводит выходной кадр в кадр сюжета через `Freeze`, звук сдвигается по тому же списку. Пауза не должна попадать на шторку.

Между мирами шторка тёмно-зелёного цвета за 8 кадров (`Curtain` в `src/Video.tsx`), внутри одного мира короткое растворение содержимого за 6 кадров. Локальный кадр 0 сцены это начало перекрытия, поэтому в файлах сцен тайминг записан глобальными кадрами через `G(кадр)`.

## Где что

- `src/data.ts`: все числа, импорт `docs/pitch/data/*.json` и `bench/results_ensemble.json`. Источники в `out/numbers-check.md`.
- `src/three/Stage.tsx`: общая 3D-сцена на `@remotion/three`. Один ключевой свет сверху-слева, один контровой, окружение из сферы с градиентом (без бликов-«шаров»), пол только с мягкой тенью, матовые материалы из брифа. Камера задаётся функцией от кадра; `project()` той же камерой ставит HTML-подписи к 3D-объектам.
- `src/three/Coins3D.tsx`: монеты. Геометрия импортируется из `pitch/slides/src/coins.ts` (там же, что на титуле деки и во `frontend/src/components/tengeScene.ts`); чтобы three был один, `remotion.config.ts` направляет импорт `three` в `node_modules` ролика.
- `src/lib.tsx`: язык движения из `pitch/slides/src/motion.ts` в кадрах, одометр по разрядам, заголовки Unbounded с наливом веса 250 → 700 за 20 кадров, чип источника, κ курсивом Source Serif 4 (в Unbounded нет греческих букв).
- `src/scenes/S1Title.tsx` … `S8Finale.tsx`: сцены по раскадровке.
- `scripts/sound.py`: звук синтезируется кодом, без сэмплов. Каждое событие привязано к тому же глобальному кадру, что и в сценах. Если меняете тайминг, поправьте событие в `build()`.

## Детерминизм

Всё, что движется, считается из номера кадра. Россыпь монет строится генератором mulberry32 с фиксированным seed, `Math.random` в ролике не используется. Повторный рендер одного кадра даёт тот же PNG.
