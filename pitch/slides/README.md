# Презентация для защиты CQA

Одна HTML-презентация на 11 слайдов и 4 резервных. Слайды идут до демо (1–7, около 1,5 минуты) и после (9–11, около 40 секунд). Слайд 8 напоминает порядок демо.

## Как открыть

Откройте `dist/index.html` двойным щелчком. Сервер и сеть не нужны: скрипты, стили, шрифт для чисел и снимки встроены в файл. Холст 1920×1080 масштабируется под окно с сохранением пропорций.

Запасные варианты, если браузер недоступен:

- `dist/cqa-pitch.pdf`: все слайды в финальном состоянии, 16:9;
- `dist/png/*.png`: каждый слайд отдельной картинкой 1920×1080.

## Клавиши

| Клавиша | Действие |
|---|---|
| → ↓ пробел Enter PageDown | следующий шаг, после последнего шага следующий слайд |
| ← ↑ Backspace PageUp | шаг назад; с первого шага на предыдущий слайд в финальном состоянии |
| Home / End | первый слайд / финал (слайд 11) |
| N | окно заметок: текст, таймер, следующий слайд, кнопки «Назад» и «Дальше» |
| G | сетка всех слайдов, щелчок открывает слайд, Esc закрывает |
| F | полный экран |
| P | режим печати: все слайды подряд, все шаги, без анимаций |

Буквы работают и в русской раскладке. Адрес хранит позицию (`#5.2`: слайд 5, шаг 2), поэтому после перезагрузки страница откроется там же. Если в системе включено «уменьшение движения», слайды открываются сразу целиком, без шагов.

Окно заметок открывается через `window.open` и синхронизируется по `BroadcastChannel`, с запасным каналом `postMessage`. Если браузер блокирует всплывающее окно, разрешите его для этого файла. Удобно вывести заметки на ноутбук, а слайды на проектор.

Резервные слайды R1–R4 идут после финала: звонки, локальный режим, таблица 16 моделей, ограничения. Быстрее всего открыть их через G.

## Шрифты

Все шрифты встроены в файл (лицензия OFL), поэтому презентация, PNG и PDF выглядят одинаково на любом компьютере:

- Unbounded: заголовки и герой-числа, вес «наливается» с 250 до 700;
- Geologica: одно акцентное слово в заголовке, оси `slnt` и `SHRP` ловят фокус;
- Onest: текст, не анимируется;
- JetBrains Mono: данные, коды критериев, идентификаторы, `tabular-nums slashed-zero`;
- Source Serif 4 Italic: только вырезки цитат, подключены латиница и кириллица.

## Движение

Каждое движение привязано к шагу: ведущий жмёт пробел, что-то происходит. Возврат стрелкой влево показывает предыдущий шаг сразу, без проигрывания. Повторный заход на слайд проигрывает его с шага 1.

**Токены** лежат в `src/style.css`, в `:root`: `--ease-out`, `--ease-io`, `--ease-snap` (перелёт до 4%, только для мелких отметок), длительности `--t-1` 180 мс, `--t-2` 420, `--t-3` 720, `--t-4` 1100, `--stagger` 45 мс. Анимируются только `transform`, `opacity`, `clip-path`, `stroke-dashoffset` и оси шрифта. Въезд идёт снизу на 24 px, выход вверх на 12 px за 60% времени.

**`src/motion.ts`** (Web Animations API, без зависимостей):

- `splitWords`, `splitChars`: делят текст на `span` с `--i`, полный текст уходит в `aria-label`;
- `reveal(el, {mode: 'mask' | 'rise' | 'weight'})`: маска, подъём или налив веса по буквам;
- `odometer(el, text, {from})`: колонка цифр на разряд, старшие встают раньше. В конце в элементе остаётся обычный текст. Округление ROUND_HALF_UP как в продукте (`roundHalfUp`, `fmt`);
- `drawPath`, `flip` (FLIP для перестановок), `wait`;
- `settled()`: ждёт все `document.getAnimations()`. Экспорт вызывает его через `deck.settle()` перед каждым кадром.

**Где что движется:**

| Слайд | Герой-момент |
|---|---|
| Все | налив веса в заголовке, линия под акцентным словом, одометр номера слайда |
| Титул | монеты поворачиваются на 2,5° за шаг, линия под названием |
| 2 | три выбранные плитки, затем волна по диагонали и одометр 100% |
| 3 | колода вырезок, карточки вытягиваются на места, маркер по цитате |
| 4 | точки падают по цене, лестница Парето, кольца у выбранных, магнит под курсором |
| 5 | узлы по колонкам, токен `ru-020` раздваивается у судей, при споре красная ветка идёт к арбитру, на «Баллы кодом» выпадает 92,31 |
| 6 | бары растут, затем сортируются (FLIP), у трёх трудных причины из данных |
| 7 | бегунок по шкале времени, старое число зачёркивается, новое идёт одометром |
| 8 | окно приложения, наезд камеры 3%, рамка фокуса, курсор к месту клика |
| 9 | четыре герой-карточки, роза весов: N/A сереет и отдаёт вес, итог 60 → 92,31 |
| 10 | плитки переворачиваются, на обороте пункт из `facts.ours` |
| 11 | строки маской, QR собирается из модулей по диагонали |

Переходы: между обычными слайдами работают View Transitions (старый уходит вверх на 16 px, полоса и номер морфятся). Перед главами 01–05 проходит шторка `--chrome` с названием. Если View Transitions нет (Firefox), слайд сменяется сразу.

**Как отключить:**

- всё движение: системная настройка «уменьшить движение» (`prefers-reduced-motion`). Слайды открываются сразу целиком, остаются смены прозрачности по 120 мс;
- для печати и экспорта движение выключает `body.instant`;
- шумовая текстура: `--noise: 0` в `:root`;
- бегущая строка на титуле и финале: удалить `${marquee()}` в `src/slides.ts`.

## Пересборка

Нужны Node.js 20+ и один раз Chromium для Playwright.

```powershell
cd pitch/slides
npm install
npx playwright install chromium   # один раз
npm run build     # dist/index.html
npm run export    # dist/png/*.png и dist/cqa-pitch.pdf
npm run check     # цитаты, длинные тире, внешние ресурсы, тайминг заметок
```

`npm run all` выполняет все три шага подряд. Свой Chromium можно указать переменной `CHROMIUM_PATH`.

Снимки из `docs/screens/2x` (октагон, звонок, четыре экрана для демо) пережаты в WebP скриптом `python scripts/prepare_assets.py` (нужен Pillow). Перезапускайте его, только если поменялись исходные снимки.

## Откуда цифры

Все числа берутся при сборке из `docs/pitch/data/*.json`: `src/data.ts` импортирует файлы, `src/slides.ts` подставляет значения. Если поменять JSON и пересобрать, слайды обновятся. Таблица «число → файл и поле» лежит в `numbers-check.md`.

## Устройство

| Файл | Что внутри |
|---|---|
| `src/main.ts` | движок: масштаб, шаги, клавиши, сетка, печать, окно заметок, переходы и шторки глав |
| `src/motion.ts` | библиотека движения: налив веса, одометр, FLIP, `settled()` |
| `src/slides.ts` | содержимое слайдов, графики SVG, заметки докладчика |
| `src/data.ts` | импорт JSON и форматирование чисел |
| `src/coins.ts` | 3D-монеты из `frontend/src/components/tengeScene.ts` с кадром для печати |
| `src/icons.ts` | иконки слайдов 10 и 11, значки узлов схемы |
| `src/style.css` | токены продукта, сетка 8 px, радиусы 24 = 8 + 16 |
| `scripts/export.mjs` | PNG и PDF через Playwright |
| `scripts/check.mjs` | автоматические проверки |
| `scripts/qr.mjs` | QR на репозиторий |

Шаг слайда задаётся атрибутом `data-s="N"`: элемент появляется на шаге N. Атрибут `data-until="M"` скрывает элемент с шага M.

## Последняя проверка

`npm run check`, темп чтения 140 слов в минуту:

- один HTML, около 1,6 МБ, без внешних ресурсов (рост к прошлой версии 26%, лимит 30%);
- 4 цитаты дословно совпадают с `quote`, от 3 до 9 слов;
- длинных тире на слайдах нет;
- заметки 1–7: около 84 с (лимит 90), 9–11: около 39 с (лимит 60), всё без демо: около 128 с (лимит 150);
- долгих задач (больше 50 мс) на слайде архитектуры нет даже при программном рендеринге.
